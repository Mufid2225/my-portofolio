# Portfolio — Muhammad Mufid Arhaburrizky

Personal portfolio website built with Next.js 16, TypeScript, Tailwind CSS v4, shadcn/ui, and Framer Motion.

## Tech Stack

| | |
|---|---|
| Framework | Next.js 16 (App Router) |
| Language | TypeScript (strict) |
| UI | shadcn/ui v4, Radix, Base UI |
| Styling | Tailwind CSS v4 |
| Animation | Framer Motion 12 |
| Icons | Lucide React |
| Package Manager | Bun |

## Features

- Responsive dark-themed portfolio with emerald accent
- Animated hero with cycling nickname text
- Project showcase with detail pages
- Skills section with logo carousel
- About page with tech icons
- Toast-based error handling + debug page

## Getting Started

```bash
bun install
bun dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
bun run build
```

## Deploy

Recommended: [Vercel](https://vercel.com) — connect the GitHub repo and it deploys automatically.
